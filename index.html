結果をシェアする 📣

※ 本シミュレーションの結果は将来の運用成果を予測・保証するものではありません。

※ 積立タイミングは期首払い（月初）、IRR（内部収益率）方式を採用しています。実際の積立タイミングを正確に反映するため、金融庁つみたてシミュレーターより保守的な（低めの）将来価値を算出します。

※ 税金・手数料・インフレ等は考慮していません。実際の資産運用・投資判断はご自身の責任において行ってください。

■ 月次利率の換算
r月 = (1 + r年)^(1/12) − 1
例：年利10% → r月 = 1.10^(1/12) − 1 ≈ 0.7974%

■ 将来価値（積立FV・期首払い／IRR方式）
FV = C × (1 + r月) × { (1 + r月)^n − 1 } / r月
C：毎月の積立額　n：積立月数（年数×12）
※ 期首払い（月初積立）のため、金融庁方式（期末払い）より各月の投資が1ヶ月多く複利運用されます。

■ 金融庁方式との違い
金融庁方式（期末払い）：FV = C × { (1 + r月)^n − 1 } / r月
IRR方式（期首払い）：FV = C × (1 + r月) × { (1 + r月)^n − 1 } / r月
→ IRR方式は過去の実績利回りをそのまま入力できるため、実績ベースの将来予測に適しています。

■ ① 必要積立額を求める式
C = FV × r月 / { (1 + r月)^n − 1 }

【例】目標700万円・年利10%・20年（240ヶ月）
r月 = 1.10^(1/12) − 1 ≈ 0.797414%
C = 7,000,000 × 0.00797414 / (1.00797414^240 − 1)
　 = 55,819 / 5.7275
　 ≈ 9,746円

■ ② 必要積立期間を求める式
n = log(1 + FV × r月 / C) / log(1 + r月)

【例】目標700万円・年利10%・月1万円積立
r月 ≈ 0.797414%
n = log(1 + 7,000,000 × 0.00797414 / 10,000) / log(1.00797414)
　 = log(1 + 55.819) / log(1.00797414)
　 = log(56.819) / 0.003946
　 ≈ 237.5ヶ月 ÷ 12 ≈ 19.8年

■ 月次利率の換算
r月 = (1 + r年)^(1/12) − 1
例：年利3% → r月 = 1.03^(1/12) − 1 ≈ 0.2466%

■ ① 何年何ヶ月でゼロ？（枯渇月数）
毎月末に引出額Wを受け取り、残高を複利運用するシミュレーション。
残高B(m) = B(m−1) × (1 + r月) − W
B(0) = 初期資金P　→　B(m) ≤ 0 となる最初の月mが枯渇月
※ r月 > 0 のとき理論的な枯渇月数は対数で解けますが、
　 このシミュレーターでは月次シミュレーションで正確に算出しています。

【例】初期資金1,000万円・年利3%・毎月5万円引出し
r月 = 1.03^(1/12) − 1 ≈ 0.2466%
月次で残高を追うと、約25年5ヶ月で枯渇

■ ② 毎月いくら引き出せる？（元利均等取り崩し）
W = P × r月 / { 1 − (1 + r月)^(−n) }
P：初期資金　r月：月次利率　n：取り崩し月数（年数×12）
※ r月 = 0（年利0%）のとき W = P / n

【例】初期資金1,000万円・年利3%・20年間（240ヶ月）
r月 ≈ 0.2466%
W = 10,000,000 × 0.002466 / (1 − 1.002466^(−240))
　 = 24,660 / (1 − 0.5536)
　 = 24,660 / 0.4464
　 ≈ 55,245円

■ ③ 何%で運用すればいい？（必要利回りの逆算）
W = P × r月 / { 1 − (1 + r月)^(−n) } を r月 について解く閉じた式はないため、
二分法（バイセクション法）で数値的に r年 を算出しています。

【例】初期資金1,000万円・毎月6万円・20年間（240ヶ月）
6万円 > 元本均等（41,667円）なので利回りが必要
二分法で収束 → 年利約4.93%が必要
